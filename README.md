# MeloLab Windows Updates

This public repository hosts official Windows installation releases and update metadata for MeloLab DAW.

- Download release assets from the **Releases** section.
- The Windows installed (NSIS) build supports app-managed updates from a newer published release.
- Portable builds are updated manually.
- Project files (`.melolab`), personal audio, and source code are not published here.

For safety, back up your project before installing updates.
